# AnimeTrack 12.0 — One library for anime and TV

- TVMaze shows now enter the native anime-style library model, with the same cards, seasons, episode controls, continuation, filters, activity and calendar.
- Existing legacy tvShows are normalized into the shared library at load/cloud import without duplicating entries or losing watched episode IDs. The previous source remains in the existing cloud snapshot until the next authorized save.
- Dexter, New Blood, Original Sin and Resurrection merge into one library title with separate labeled seasons and source IDs.
- Unified search opens and adds TVMaze shows to the shared library. TV results and anime share the same global search.
- All/Anime/TV are presentation filters; statuses and statistics are shared.
- New service worker cache version 12.0.0.
- TV metadata comes from TVMaze; schedule availability depends on dates supplied by TVMaze.
